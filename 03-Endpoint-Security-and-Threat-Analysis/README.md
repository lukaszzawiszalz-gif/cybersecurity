# 03. Endpoint Security and Threat Analysis

## Overview
This directory contains practical projects and security exercises focused on **endpoint security**, **threat analysis**, and mitigating physical and technical attack vectors. 

The projects documented here reflect real-world principles of evaluating vulnerabilities associated with hardware devices, removable media, and compromised endpoints, while applying industry-standard frameworks to secure organizational environments.

---

## Core Competencies Demonstrated
- **Endpoint Protection:** Securing physical ports, managing removable media, and deploying automated threat detection to prevent unauthorized access.
- **Physical Security Incident Analysis:** Investigating social engineering scenarios such as USB baiting to understand attacker methodologies (PII exposure, malware distribution).
- **Multi-Layered Defense (Defense-in-Depth):** Implementing technical (EDR/DLP port controls), operational (isolated virtual sandbox environments), and managerial controls.
- **Threat & Risk Assessment:** Evaluating the potential business impact of physical media vulnerabilities and mapping out effective mitigation strategies.

## General Takeaways
Effective endpoint security requires recognizing that physical hardware and removable media represent significant entry points for malicious actors. Securing endpoints relies on combining technical restrictions (port disabling, device control policies) with user awareness training to neutralize human-centric attack vectors like USB baiting.
