# 03. Endpoint Security and Threat Analysis

## Domain Overview
This directory contains practical projects and security exercises focused on endpoint security, threat analysis, and mitigating physical and technical attack vectors. The primary goal is to evaluate vulnerabilities associated with hardware devices, removable media, and compromised endpoints, while applying industry-standard frameworks to secure organizational environments.
