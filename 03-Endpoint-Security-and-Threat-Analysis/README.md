# USB Drive Threat & Risk Assessment (Parking Lot Scenario)

## Project Overview
This project simulates a common physical security threat known as **USB baiting**. In this scenario, an unfamiliar USB drive bearing a hospital logo is discovered in an employee parking lot. The objective is to analyze the potential risks from both a target and an attacker perspective, evaluate data exposure, and outline mitigating controls.

---

## Key Analysis & Findings

* **Data Exposure (Contents):** The drive contained a mix of personal files (family photos, wedding lists) and sensitive work-related documents (new hire letters, shift schedules, employee budgets). This highlights the security risks of mixing personal and corporate data on removable media.
* **Attacker Perspective (Attacker Mindset):** Threat actors can leverage harvested PII and internal structure data to conduct highly targeted spear-phishing, social engineering campaigns, or execute authorized impersonation attacks to breach organizational perimeters.
* **Risk & Mitigation Analysis:** Unverified USB devices pose severe malware delivery risks (e.g., ransomware, trojans, worms). Mitigation requires a combination of technical controls (EDR/DLP port blocking, endpoint hardening), operational procedures (strict handling of external media in isolated virtual environments), and managerial controls (regular security awareness training).
