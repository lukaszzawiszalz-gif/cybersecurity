# 03. Endpoint Security and Threat Analysis

## Domain Overview
This directory contains practical projects and security exercises focused on **endpoint security**, **threat analysis**, and mitigating physical and technical attack vectors. The primary goal is to evaluate vulnerabilities associated with hardware devices, removable media, and compromised endpoints, while applying industry-standard frameworks to secure organizational environments.

---

## Projects in this Section

### 1. USB Drive Threat & Risk Assessment (USB Baiting)
* **Directory:** `usb-drive-threat-risk-assessment/`
* **Description:** Evaluates a physical security incident involving a found USB drive (USB baiting scenario). The project analyzes data exposure risks (PII, sensitive business information), maps out attacker methodologies (social engineering, spear-phishing, malware distribution), and outlines defense strategies using technical (EDR/DLP port controls), operational (isolated virtual sandbox environments), and managerial controls.

---

## Key Frameworks & Security Controls
* **Endpoint Protection:** Securing physical ports, managing removable media, and deploying automated threat detection.
* **Threat Mitigation:** Implementing multi-layered defense controls to prevent unauthorized network access and malware propagation via endpoints.
