# Network Hardening & Security Risk Assessment

## Project Overview
This project addresses a major data breach at a social media organization caused by undiscovered network vulnerabilities. As a security analyst, the objective is to evaluate critical network weaknesses—such as shared passwords, default administrator credentials, unconfigured firewalls, and lack of multifactor authentication (MFA)—and propose effective network hardening controls.

---

## Implemented Hardening Controls & Methodology
1. **Multi-Factor Authentication (MFA):** Implemented to eliminate risks associated with password sharing and credential stuffing by enforcing secondary verification methods.
2. **Firewall Maintenance:** Regular review and updating of firewall rules to establish strict traffic filtering (inbound and outbound) and mitigate unauthorized access.
3. **Password Policies:** Establishing robust password standards (aligned with NIST guidelines) to eradicate default database passwords and weak credentials.
